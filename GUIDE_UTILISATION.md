# MF/1.2 Iris Studio — Guide d'utilisation

Ce guide suit l'ordre réel de votre activité : **préparer** une fois l'application, **préparer** chaque séance, **vendre** le jour J, puis **produire, livrer et suivre** vos résultats.

L'application fonctionne entièrement sur votre Mac, sans Internet. Tout est enregistré automatiquement : il n'y a pas de bouton « Enregistrer le fichier ».

## 1. Découvrir l'interface

**La barre latérale (à gauche)** donne accès à tous les modules :

| Menu | À quoi ça sert |
|---|---|
| Tableau de bord | Vue d'ensemble : ventes, encaissements, production, prochaines séances |
| Séances | Créer et gérer chaque séance (le cœur de l'application) |
| Planning | Les rendez-vous de la séance choisie |
| Clients | La base de toutes les familles |
| Commandes | Toutes les commandes et leurs règlements |
| Postproduction | Ce qu'il reste à réaliser, imprimer et livrer |
| Catalogue | Vos styles de montages (avec exemples) et vos produits |
| Templates tarifaires | Vos grilles de prix et vos offres |
| Fournisseurs | Prix d'achat (Onelab Pro déjà rempli) |
| Rentabilité | Résultat de chaque séance |
| Documents PDF | Catalogue, grille, récapitulatif client, fiche de production |
| Paramètres | Coordonnées, code PIN, sauvegardes, exports |

**En bas à gauche**, le bouton doré **Mode présentation** bascule l'écran en vue client (voir [§4.3](#43-montrer-les-créations-au-client-mode-présentation)).

**Repères visuels communs :**
- Les messages de confirmation ou d'erreur apparaissent brièvement en bas à droite.
- Dans les tableaux : cliquez sur un **titre de colonne** pour trier, utilisez la **loupe** pour rechercher, et cliquez sur une **ligne** pour ouvrir le détail.
- Les suppressions importantes demandent toujours une confirmation.

## 2. Configuration initiale (une seule fois)

Comptez environ 30 minutes. Faites ces étapes dans l'ordre.

### 2.1 Paramètres
**Paramètres** → bloc *Identité & coordonnées* :
1. Renseignez votre nom commercial, votre sous-titre, votre nom, votre e-mail, votre téléphone, votre site et votre adresse. Ces informations apparaissent sur les PDF et en mode présentation.
2. Bloc *Mode présentation client* : **changez le code PIN** (4 à 8 chiffres). Le code par défaut est `1212`.
3. Cliquez sur **Enregistrer** (en haut à droite).
4. Bloc *Fiscalité* : laissez **« TVA récupérable » désactivé**. C'est le bon réglage pour une micro-entreprise en franchise de TVA : vos coûts d'achat sont alors comptés TTC.

### 2.2 Catalogue — vos styles de montages
**Catalogue** → onglet **Styles de montages**. Cinq styles sont déjà créés : Iris naturel, Collection, Fusion, Anneau et Explosion.

Pour chaque style :
1. Cliquez sur la carte du style.
2. Vérifiez le nom, la description (le client la verra) et le **nombre d'iris minimum et maximum**. Par exemple, une Fusion va de 2 à 6 iris.
3. Choisissez éventuellement dans la liste le nombre d'iris correspondant aux images, puis cliquez sur **Importer des images**. Vous pouvez en sélectionner plusieurs (JPEG ou PNG). Les miniatures sont générées automatiquement.
   - Conseil : pour la Fusion, importez un exemple « 2 iris », un « 3 iris », etc. Le client verra l'exemple qui correspond à son nombre d'iris.
4. Pour chaque image, la petite liste en dessous permet de changer le nombre d'iris associé. La corbeille la supprime.
5. **Photo à la une** : l’image marquée ★ *À la une* sert de vignette du style (catalogue, cartes de vente, présentation client, catalogue PDF). Pour en choisir une autre, cliquez sur ☆ *Mettre à la une* sur l’image voulue.
5. Cliquez sur **Enregistrer**.

Autres actions :
- **Nouveau style** : la carte « + » en fin de liste.
- **Actif** : quand cette option est décochée, le style n'est plus proposé à la vente.
- **Archivé** : le style disparaît des listes mais reste dans l'historique des commandes.

> Les images sont des **exemples de réalisations**. L'application rappelle toujours au client que sa création sera réalisée avec ses propres iris.

### 2.3 Catalogue — vos produits
Onglet **Produits & variantes** :
- **Numérique** : Iris individuel HD, Collection HD, Fusion HD, Anneau HD, Explosion HD et Fichiers supplémentaires.
- **Impressions** : Acrylique 3 mm, Acrylique 5 mm, Alu Dibond et HD Metal Print, chacun en **12 formats**, du 20 × 20 au 60 × 90 cm.

Cliquez sur un produit pour :
- modifier son nom, sa description et son image ;
- le relier à un **style**. Par exemple, « Fusion HD » n'est proposé que pour une création Fusion ;
- choisir s'il est **rattaché à une création**. Un tirage, oui ; un « fichier supplémentaire », non ;
- gérer ses **variantes** (formats) :
  - ajouter un format ;
  - désactiver un format avec l'interrupteur ;
  - saisir un « **Coût interne +** » par unité (coût, pas prix de vente), par exemple une fixation ou un emballage ;
  - choisir le fournisseur préféré.

> Supprimer un format déjà vendu l'**archive** automatiquement : l'historique est conservé.

### 2.4 Fournisseurs (déjà prêt pour Onelab)
**Fournisseurs** → **Onelab Pro** : saisissez vos prix d'achat (bouton *Nouveau prix*) ou importez-les par CSV. Les produits d'impression et leurs formats existent déjà dans le Catalogue.

- La colonne **Coût réel** est le prix TTC que vous payez vraiment. C'est celui qui sert au calcul des marges.
- **Nouveau prix** : quand Onelab change un tarif, saisissez le nouveau prix. L'ancien est conservé dans l'**historique** (icône horloge).
- **Livraison / unité** (bouton *Modifier* du fournisseur) : vous pouvez y répartir une estimation des frais de port par tirage.
- **Import CSV** : bouton *Modèle CSV*, à remplir dans Excel, puis *Import CSV*. Les lignes sans prix, ou sans « oui/non » dans la colonne *Prix TTC*, sont refusées : aucun prix n'est inventé.
- **Produit fournisseur absent du Catalogue** (ex. un cadre) : ouvrez sa ligne → *Créer dans le catalogue et lier* (choisissez la catégorie, ex. Options), ou *Ajouter les non liés au catalogue* pour tous d'un coup. Fixez ensuite son prix de vente (template **et** Séance → Paramètres).
- Onglet **Comparateur** : pour un format donné, il affiche le prix catalogue, la remise, la TVA, le port, le coût réel, votre prix de vente et la marge.

### 2.5 Templates tarifaires — vos prix de vente
**Templates tarifaires** → **Tarif public**. Aucun prix n'est pré-rempli : c'est à vous de les fixer.

**a) Créations photographiques** (en haut) : c'est le prix de la création, facturée **une seule fois** même si elle est déclinée sur plusieurs produits.
- La colonne **Tous** donne le prix par défaut.
- Les colonnes **1 iris … 6 iris** donnent un prix spécifique selon le nombre d'iris (facultatif).
- Tapez le montant et appuyez sur Entrée : c'est enregistré.
- Mettez **0** si la création est incluse dans le prix des produits. Elle s'affichera « Inclus ».

**b) Numérique / Impressions / Options** : un prix par format.
- **Mode Manuel** : vous tapez le prix.
- **Coefficient sur tous les formats…** (sous le nom du produit) : applique en un clic le même coefficient à tous les formats d’un produit, par exemple `+7 %` ou `1,07` pour vendre les cadres 7 % au-dessus du coût de revient. Si un coût change ensuite, relancez-le pour recalculer.
- **Mode Coefficient** : le prix est égal au coût multiplié par le coefficient (par exemple × 3). Il se calcule tout seul à partir du coût Onelab.
- **Mode Taux de marque** : vous indiquez la marge voulue (par exemple 65 %) et le prix est calculé en conséquence.
- Les colonnes **Coût revient, Marge, Taux de marque et Coef.** vous aident à décider. Elles ne sont jamais montrées au client.

> Un produit **sans prix** reste visible mais grisé : on ne peut pas le vendre.

**c) Packs & promotions** (en bas) → **Ajouter** :

| Type | Exemple | Réglage |
|---|---|---|
| Pack | « Fichier HD + tirage » | Éléments du pack plus un **prix fixe** ou une **remise en €**. Détecté automatiquement dans le panier. |
| Remise % | « −10 % sur les impressions » | Sur la commande, une catégorie, un style ou un produit |
| Remise € | « −10 € dès 100 € », « −10 € sur le fichier HD » | Montant, sur toute la commande **ou** sur une catégorie, un style ou un produit (jamais plus que leur prix) |
| Remise quantité | « −15 % dès 2 impressions » | Quantité minimum et pourcentage |

- **Condition de montant** (toutes les offres) : *Dès* et *Jusqu’à*, calculés sur le prix normal avant remises. Paliers possibles, par exemple :
  - « Fichier HD −10 € » : Remise € de 10 € sur la catégorie Numérique, de 150 € à 199,99 € ;
  - « Fichier HD offert » : Remise % de 100 % sur la catégorie Numérique, **limité à 1 article**, dès 200 € (montant calculé sur les *Impressions seulement* pour récompenser les tableaux).
- **Limiter à N articles** : sans limite, une remise sur une catégorie s’applique à **tous** ses articles (100 % sur Numérique = tous les fichiers offerts). Avec 1, seul l’article le moins cher est remisé.
- **Montant calculé sur** : toute la commande, ou une seule catégorie (ex. « dès 200 € d’impressions »).
- Un article déjà offert ne peut pas être remisé une seconde fois par une autre offre.
- **Priorité** : les offres sont examinées de la plus petite valeur à la plus grande.
- **Cumulable** : décochez cette option pour qu'une offre ne s'applique que seule.
- Un pack prend les articles **les moins chers** qui correspondent, pour protéger votre marge. Il ne s'applique jamais deux fois, sauf si l'option « Applicable plusieurs fois » est cochée, et le total ne devient jamais négatif.

**d) Autres actions** :
- **Nouveau template** : par exemple « Tarif TEMPSDANSES » ou « Tarif événement ».
- **Dupliquer** : copie complète, prix et offres compris.
- **Comparer** : deux grilles côte à côte, avec les écarts de prix.
- **Archiver** : le template n'est plus proposé.
- **Conditions commerciales** : ce texte est imprimé sur le catalogue PDF.

## 3. Préparer une séance

### 3.1 Créer la séance
**Séances** → **Nouvelle séance** :
1. Saisissez le nom (par exemple *TEMPSDANSES — Iris novembre 2026*), la date, l'heure de début et de fin, le lieu et l'organisateur.
2. Indiquez la **durée d'un créneau** (20 min par défaut) et le **nombre de familles par créneau**.
3. Choisissez le **Template tarifaire** : la séance reçoit **sa propre copie** des prix.
4. Cliquez sur **Enregistrer** : la fiche de la séance s'ouvre.

> Pourquoi une copie ? Si vous modifiez plus tard le template, les séances existantes ne changent pas sans que vous le sachiez. Les commandes validées gardent toujours leurs prix d'origine.

La fiche séance comporte 7 onglets : **Vue générale, Inscrits, Planning, Commandes, Postproduction, Finances, Paramètres**.

### 3.2 Préparer les inscriptions dans Excel
Onglet **Inscrits** → **Télécharger le modèle CSV**. Ouvrez-le dans Excel. Il contient les colonnes suivantes :

`Référence inscription ; Nom de famille ; Prénom du contact ; Téléphone ; E-mail ; Date du rendez-vous ; Heure du rendez-vous ; Nombre de participants ; Participant 1 … Participant 5 ; Notes`

Règles :
- Seul le **Nom de famille** est obligatoire.
- La date s'écrit `21/11/2026`, l'heure `14:30` ou `14h30`.
- Mettez les colonnes **Téléphone** et **Référence** au format **Texte** dans Excel (clic droit → Format de cellule → Texte) pour garder les zéros. Si Excel a quand même retiré le 0 d'un portable, l'application le remet.
- Enregistrez au format **CSV UTF-8 (séparateur point-virgule)**. Les anciens formats CSV d'Excel sont aussi acceptés.

### 3.3 Importer les familles
**Importer les clients CSV** → **Sélectionner le fichier CSV**. Un **aperçu** s'affiche avant tout enregistrement :
- **Vert « Créer »** : nouvelle famille.
- **Bleu « Rattacher »** : famille déjà connue d'une séance précédente. Elle est réutilisée, sans doublon.
- **Orange « déjà inscrite »** : la famille est déjà dans cette séance. Pour chacune, choisissez :
  - **Ignorer** (par défaut) ;
  - **Mettre à jour** : coordonnées, horaire, participants ajoutés. Rien n'est supprimé ;
  - **Créer une nouvelle inscription**.
- **Rouge** : ligne en erreur (date invalide, nom manquant…), non importée. Corrigez-la dans Excel et réimportez.

Cliquez sur **Importer N ligne(s)**. Vous pouvez réimporter le même fichier sans risque : rien n'est créé en double, et les commandes ne sont **jamais** modifiées par un import.

### 3.4 Ajouter une famille à la main
- **Ajouter une famille** : nouvelle fiche avec ses participants.
- **Famille existante** : recherche dans la base clients, puis inscription à la séance.

Dans la liste des inscrits :
- le **crayon** modifie le rendez-vous (date, heure, statut, référence, notes) ;
- la **corbeille** retire la famille de la séance, sans supprimer sa fiche client ;
- un clic sur le **nom** ouvre la fiche, où l'on ajoute par exemple les références photo.

### 3.5 Vérifier le planning
Onglet **Planning** :
- **Journée** : chaque créneau horaire avec ses familles. **Glissez-déposez** une famille pour la déplacer. Un avertissement orange signale un créneau qui dépasse la capacité.
- **Liste chronologique** : toutes les familles dans l'ordre.
- **Créneaux** : remplissage de chaque créneau (par exemple 1/1).
- En haut : Inscrits, Reçues, **Restant à recevoir**, Absents.

### 3.6 Avant le jour J
- **Vue générale** → **Catalogue PDF de la séance**, à imprimer ou à envoyer à l'organisateur.
- **Paramètres** (onglet de la séance) : les prix propres à la séance se modifient ici sans toucher au template. Vous pouvez aussi désactiver une offre pour cette séance seulement.
- Passez le **statut** de la séance à **Active** (*Paramètres → Modifier*).

## 4. Le jour de la séance

### 4.1 Accueillir une famille
Ouvrez **Planning** (menu de gauche) : il affiche la séance active.
1. La famille arrive : cliquez sur **Arrivée** (statut *Présent*).
2. Pour retrouver une famille, utilisez la recherche par nom, référence ou prénom d'un enfant.
3. Photographiez les iris. Vous pouvez ensuite noter les références des fichiers (par exemple `IRIS_0001`) dans la fiche famille, depuis l'onglet *Inscrits*, en cliquant sur le nom.

### 4.2 Construire la commande (configurateur de vente)
Cliquez sur **Vendre** à côté de la famille. Pour corriger le nom, le prénom, le téléphone, l’e-mail ou le rendez-vous d’un inscrit : crayon **Modifier l’inscription** (liste des inscrits ou planning) ; *Participants et références photo…* pour les enfants. L'écran se divise en deux : le catalogue à gauche, le **panier** à droite, avec le total toujours visible.

1. **Ajout rapide** : cochez **« Ajouter »** en haut à gauche d’une carte de style. La création est ajoutée directement avec les iris de la famille (tous les participants, dans la limite du style ; pour l’Iris naturel, le premier participant). Décochez pour la retirer. Si le nombre d’iris ne convient pas au style (ex. Fusion avec un seul participant), la fenêtre de choix s’ouvre.
   Pour choisir précisément les iris ou voir les exemples, cliquez sur la carte elle-même :
1. **Onglet Créations** : cliquez sur un style (par exemple Fusion).
   - Agrandissez les exemples d'un clic.
   - **Cochez les prénoms** dont les iris seront inclus : le nombre d'iris se calcule tout seul et le prix s'adapte.
   - Choisissez la **disposition des iris** : horizontale, verticale ou diagonale (croquis à l’appui ; non proposé pour 1 iris). Elle reste modifiable dans le panier (« Disposition : … »), y compris après un ajout rapide.
   - Ajoutez si besoin des souhaits (ordre des iris, fond…). Ils s’affichent dans le panier, la fiche commande, la postproduction, la fiche de production **et le récapitulatif PDF du client**.
   - **Ajouter cette création** : elle apparaît dans le panier, encadrée en doré, c'est-à-dire **active**.
2. **Onglet Numérique** : cliquez sur le fichier HD voulu. Il s'ajoute à la création active.
3. **Onglet Impressions** — aide au choix du format :
   - en haut, l’encadré **« Conseillé pour N iris »** affiche le format recommandé pour la création sélectionnée, avec son croquis de disposition et une alternative (d’après le guide des formats : 1 iris 20 × 20, 2 iris 30 × 20, 3 iris 45 × 30, 4 iris 40 × 40, 5 iris 50 × 40, 6 iris 60 × 40) ;
   - les formats concernés portent un badge **Conseillé** / **Alternative** ;
   - **Guide des formats** : les 6 croquis de 1 à 6 iris, à montrer au client ;
   - **Visualiser la taille et la disposition →** (sous chaque support) : le tableau dessiné **à l’échelle** au-dessus d’un canapé 3 places, avec une feuille A4 pour comparaison ; choix du format et de l’orientation horizontale / verticale.
   **Onglet Impressions** : cliquez sur un support et un format, par exemple Acrylique 5 mm en 40 × 40 cm.
   - Un deuxième clic sur le même format ajoute 1 à la quantité. Vous pouvez aussi utiliser **− / +** dans le panier.
4. Pour une autre création (par exemple un iris naturel pour un enfant), retournez dans **Créations**. Pour ajouter des produits à une création existante, **cliquez d'abord dessus dans le panier**.
5. Les **packs et promotions** s'appliquent automatiquement. Le panier montre le prix normal, chaque remise avec le **nombre de fois où elle s’applique** (ex. « Pack 3 fichiers HD ×2 », ou le nombre d’articles remisés pour une remise ciblée), l'économie réalisée et le **TOTAL**. Ce nombre figure aussi sur la fiche commande et le récapitulatif PDF.
6. **Remise commerciale** (bouton sous le total) : montants rapides 5 €, 10 €, 15 €, 5 %, 10 %, ou montant / pourcentage libre ; libellé et motif facultatifs (« Geste commercial » par défaut). Elle est enregistrée dans l'historique de la commande. En mode présentation client, le bouton est aussi là mais demande votre **code PIN**. La petite corbeille à côté d'une remise la retire.
7. **Payer en plusieurs fois** (bouton à côté) : 2, 3 ou 4 fois, échéances mensuelles à partir de la date choisie (aujourd’hui par défaut). Le panier affiche « Payable en 3 fois » avec les dates et montants ; ils se recalculent si le total change. Bouton *Paiement en une fois* pour annuler. Sur la fiche commande, l’échéancier indique chaque échéance *Payée / À venir / En retard*, et le montant proposé lors d’un règlement est celui de l’échéance suivante. Le récapitulatif PDF du client reprend l’échéancier.

> Une création (par exemple une Fusion de 4 iris) n'est facturée **qu'une fois**, même si elle est déclinée en fichier HD et en plusieurs tableaux.

Ensuite, deux possibilités :
- **Brouillon** : la commande est enregistrée sans être validée. Vous la retrouvez via *Reprendre*.
- **Valider la commande** : les prix sont figés et les tâches de postproduction sont créées. Vous arrivez sur la fiche commande.

### 4.3 Montrer les créations au client (mode présentation)
Depuis le configurateur, **Montrer au client** : le panier en cours est enregistré en brouillon et retrouvé tel quel en présentation. Vous pouvez aussi utiliser le bouton doré **Mode présentation** et choisir la séance et la famille.

- Le client voit de grandes images, les produits, les **prix de vente**, ses offres et son panier.
- Il **ne voit jamais** vos coûts, marges, fournisseurs, statistiques, ni les autres familles. Le reste de l'application n'est même pas chargé.
- Il peut composer sa sélection et appuyer sur **Enregistrer ma sélection** : elle est enregistrée comme brouillon (le bouton indique ensuite *Sélection enregistrée* tant que rien ne change).
- **Valider la commande** (à côté) : demande votre **code PIN**, puis la confirmation. Les prix sont figés et la commande passe en lecture seule pour le client. Le règlement s’enregistre ensuite depuis la fiche commande (vue photographe).
- Sans famille choisie, le mode présentation affiche simplement la galerie de vos créations.
- **Passer à la famille suivante sans quitter la présentation** : *Changer de client* (en haut à droite), puis votre **code PIN**. La liste des familles de la séance s’affiche (horaire, participants, statut), avec une recherche. Un clic ouvre la famille suivante ; sa sélection en cours est reprise si elle en a une. *Catalogue seul* affiche la galerie sans famille. La liste n’apparaît jamais sans le code : le client ne voit pas les autres familles.
- **Pour sortir** : *Quitter la présentation* (en haut à droite), puis votre **code PIN**, à taper à l’écran ou au clavier (pavé numérique compris ; Retour arrière pour corriger). Même si l'application est fermée et relancée, elle reste en mode présentation jusqu'au code.

Vous pouvez valider directement en présentation (bouton *Valider la commande* + code PIN), ou après la sortie (*Planning → Reprendre*).

### 4.4 Enregistrer le règlement
L'application n'encaisse rien : vous encaissez avec vos propres moyens, puis vous notez le règlement. Sur la fiche commande, bloc **Règlements** :

- **Payé / partiel** :
  1. Le montant est pré-rempli avec le solde : ne le changez pas pour un règlement complet, ou tapez le montant reçu pour un acompte.
  2. Choisissez le mode : Carte, Espèces, Chèque, Virement ou Autre.
  3. Vérifiez la date et ajoutez une note si besoin (par exemple le n° de chèque).
- **À payer…** : indiquez une date de règlement prévue et une note.
- Vous pouvez enregistrer **plusieurs règlements** : l'application calcule le solde restant.
- Le badge passe de *À payer* à *Partiellement payé*, puis à *Payé*.

> Ne saisissez jamais de numéro de carte bancaire.

### 4.5 Remettre la facture
**Une fois** : renseignez **Paramètres → Facturation** (nom et prénom de l’entrepreneur, SIRET, adresse professionnelle, médiateur de la consommation ; « EI » et « Dispensé d’immatriculation au RCS et au RM » sont pré-remplis).

Fiche commande (validée) → **Facture PDF** :
- la première fois, la facture reçoit le **numéro suivant** (F2026-0001, F2026-0002… sans trou) et son contenu est **figé** ; les impressions suivantes sont des duplicatas identiques ;
- elle comporte le **nom et le prénom** du client, les créations (avec disposition et souhaits), les produits, remises, total, règlements reçus, reste à payer, échéancier éventuel et la mention « TVA non applicable, art. 293 B du CGI » ;
- si la commande est **corrigée, annulée ou supprimée** après facturation, un **avoir** (AV2026-0001…) annule automatiquement la facture ; l’impression suivante émet une nouvelle facture ;
- toutes les factures et avoirs sont listés dans **Documents PDF → Registre des factures et avoirs** (PDF et export CSV).

Pour une commande non validée (brouillon), le bouton reste **Récapitulatif PDF** (document non officiel).

## 5. Après la séance : postproduction et impressions

### 5.1 Retrouver tout ce qu'il faut réaliser
Menu **Postproduction** (ou l'onglet Postproduction de la séance) → onglet **Créations & tâches**. Chaque création validée affiche :
- la famille et le n° de commande ;
- le style et le nombre d'iris ;
- les participants et les **références photo** ;
- l'image d'exemple du style ;
- les souhaits du client ;
- les produits liés ;
- la date de livraison souhaitée.

Vues :
- **Tableau** : liste compacte, statut modifiable directement.
- **Kanban** : une colonne par statut ; **glissez les cartes** d'une colonne à l'autre.
- **Regroupé** : par séance, par famille, par montage ou par statut.

**Statuts** : À réaliser → En cours → Montage terminé → Fichier numérique prêt → Impression à commander → Commandé fournisseur → Reçu → Livré. Pour une création 100 % numérique, les étapes d'impression sont masquées.

Raccourcis :
- Cochez plusieurs cartes, puis choisissez un statut dans la liste « N sélection(s) → statut ».
- **Note** : une note interne sur une création.
- **Fiche de production** : PDF de toutes les créations, ou seulement de celles qui sont cochées, avec les références d'iris, à garder à côté de Photoshop.
- **CSV** : export pour Excel.

### 5.2 Commander les impressions chez Onelab
Onglet **Impressions & fournisseurs** :
1. **Impressions à commander** : les tirages sont regroupés par fournisseur, avec le coût estimé.
2. Cochez des lignes (sinon toutes sont prises), puis cliquez sur **Préparer la commande**.
3. Dans **Commandes fournisseurs**, cliquez sur la commande :
   - **CSV** ou **PDF** : le récapitulatif pour passer la commande sur le site Onelab. L'application ne commande pas automatiquement chez le fournisseur.
   - Statut **Commandée** : saisissez le **n° de commande Onelab** et la date. Les créations liées passent en *Commandé fournisseur*.
   - À réception, statut **Reçue** : saisissez le **coût réel payé** et les **frais de livraison**. Les créations passent en *Reçu*.
4. Une fois remis au client, passez les créations en **Livré** dans Postproduction.

## 6. Suivre les commandes et les règlements

Menu **Commandes** :
- Filtres : séance, statut (Brouillon / Validée / Annulée), **règlement** (Payées / Partiellement / À payer), dates.
- La colonne **Solde** signale ce qu'il reste à encaisser.
- **Supprimer des brouillons** : corbeille au bout de la ligne d’un brouillon, ou bouton **Supprimer les brouillons affichés (N)** pour tous ceux qui correspondent aux filtres (par exemple filtre *Brouillons* + une séance). Aussi possible depuis le configurateur ou la fiche du brouillon (*Supprimer le brouillon*). Pour une commande validée, la corbeille demande une confirmation renforcée (voir *Supprimer* ci-dessous).
- Un clic sur une ligne ouvre la **fiche commande** :
  - **Corriger** : modifier une commande validée. Un **motif** est demandé, la version précédente est conservée dans l'**Historique** et les lignes existantes gardent leurs prix.
  - **Dupliquer** : crée un brouillon identique, aux prix actuels.
  - **Annuler** : avec un motif. La commande reste visible avec le statut « Annulée » (conseillé pour garder une trace comptable).
  - **Supprimer** : efface définitivement la commande, même validée, avec ses règlements, ses tâches de postproduction et ses lignes de commande fournisseur. La fenêtre indique ce qui sera perdu ; il faut taper `SUPPRIMER`. Une sauvegarde de la base est faite juste avant et le contenu de la commande reste dans le journal. Aussi possible avec la corbeille dans la liste des commandes.
  - **Données internes** : coût estimé, marge et taux de marque, pour vous seul.

## 7. Clients et familles

Menu **Clients** :
- La **recherche** trouve par nom, téléphone, e-mail, référence d'inscription, prénom d'un enfant ou **référence photo**.
- Un clic sur une famille affiche ses participants et leurs références, ses séances et ses commandes.
- **Modifier** : coordonnées, participants, références photo (par exemple `IRIS_0001`), plusieurs par participant si besoin.
- **Doublons** : liste les fiches probablement identiques (même téléphone, ou même nom et même e-mail). **Fusionner** regroupe inscriptions, participants et commandes sur une seule fiche.
- **Export CSV** : toutes les familles.

Données personnelles (protection des enfants et RGPD) :
- Seul le nom de famille est obligatoire : ne collectez que le nécessaire.
- **Supprimer** : efface la famille et toutes ses données. Ce n'est possible que si elle n'a aucune commande.
- **Anonymiser** : efface le nom, les coordonnées et les prénoms, mais garde les commandes pour votre comptabilité.

## 8. Rentabilité et tableau de bord

### 8.1 Frais d'une séance
Fiche séance → onglet **Finances** :
- Ajoutez les frais : Location, Déplacement, Publicité, Consommables, Autres.
- **Temps de travail (estimé)** : facultatif, il est présenté à part.

### 8.2 Lire les résultats
Toujours dans l'onglet **Finances** :

| Indicateur | Signification |
|---|---|
| Chiffre d'affaires | Total des commandes validées, remises déduites |
| Encaissements | Ce que vous avez réellement reçu |
| Solde à encaisser | CA − encaissements |
| Coûts fournisseurs | Prévisionnels (prix Onelab), remplacés par les **coûts réels** une fois saisis sur toutes les commandes fournisseurs |
| Marge commerciale | CA − coûts fournisseurs |
| Résultat estimé | Marge − frais de la séance |

> La marge commerciale n'est **pas** un bénéfice net comptable : vos cotisations et charges générales n'y figurent pas.

Menu **Rentabilité** : il compare toutes les séances. Cliquez sur une séance pour voir son détail.

Le **Tableau de bord** donne la vue d'ensemble :
- ventes, encaissé, marge et familles ;
- produits vendus et remises ;
- tâches à produire et livrées ;
- ventes par mois ;
- répartition des montages et des supports.

Vous pouvez le filtrer par séance et par période. Si la carte « Marge » indique *Coûts fournisseurs non renseignés*, c'est qu'il manque des coûts d'achat.

## 9. Documents PDF

Menu **Documents PDF** : choisissez le type, la séance (et la commande pour un récapitulatif), puis **Générer l'aperçu** et **Enregistrer le PDF**.

| Document | Pour qui | Contenu |
|---|---|---|
| Catalogue commercial | Client | Styles avec images, prix de la séance, packs, conditions |
| Grille tarifaire | Client | Version compacte et imprimable |
| Récapitulatif client | Client | Commande, remises, total, règlements, solde |

Les PDF destinés au client n'affichent **jamais** vos coûts, fournisseurs ni marges.

## 10. Sauvegardes et sécurité des données

**Automatique** : une sauvegarde est faite au démarrage, puis toutes les 12 h tant que l'application est ouverte. Les 20 dernières sont conservées ; ce nombre se règle dans Paramètres.

**Paramètres → Sauvegardes** :
- **Sauvegarder maintenant** : à faire avant une séance, puis juste après.
- **Exporter la base…** : copie complète vers un disque externe, iCloud Drive ou Dropbox. **Faites-le après chaque séance.** Les images d'exemple sont incluses.
- **Vérifier l'intégrité** : contrôle que la base n'est pas abîmée.
- **Restaurer** une sauvegarde de la liste, ou **Restaurer un fichier…** pour un export.
  - Une confirmation est demandée (tapez `RESTAURER`).
  - Une copie de sécurité des données actuelles est faite automatiquement juste avant.

**Exports CSV** (Paramètres) : familles, inscriptions, commandes, lignes de commande, paiements, utilisables dans Excel ou par votre comptable.

Emplacement des données sur le Mac : `~/Library/Application Support/fr.mf12.irisstudio/`. Ne copiez pas ce dossier à la main pendant que l'application est ouverte : utilisez les boutons ci-dessus.

## 11. Questions fréquentes

**Un produit est grisé dans le configurateur.**
Il n'a pas de prix dans la grille de la séance : *Séance → Paramètres* ou *Templates tarifaires*.

**« Sélectionnez ou ajoutez d'abord une création ».**
Les fichiers HD et les impressions se rattachent à une création. Ajoutez une création, ou cliquez sur une création existante dans le panier.

**J'ai changé un prix dans le template mais la séance affiche l'ancien.**
C'est voulu : chaque séance a sa propre grille. Modifiez-la dans *Séance → Paramètres*, ou réappliquez le template (*Appliquer*). Les commandes déjà enregistrées gardent leurs prix.

**Le client a changé d'avis après validation.**
Ouvrez la commande, cliquez sur **Corriger**, modifiez et indiquez le motif. L'historique garde la version précédente.

**J'ai oublié le code PIN en mode présentation.**
Le code par défaut est `1212` si vous ne l'avez jamais changé. Notez votre code dans un endroit sûr.

**Je veux tester sans abîmer mes données.**
Faites d'abord *Sauvegarder maintenant*, testez, puis restaurez la sauvegarde.

**Mettre à jour l'application.**
Téléchargez la nouvelle version (page *Releases* du dépôt GitHub) et remplacez l'application dans *Applications*. Vos données sont conservées, et une sauvegarde est faite automatiquement au démarrage.
